## Why

El PRD y el ARD establecen decisiones importantes, pero aún no existe un registro de decisiones implementables y revisables. Capturarlas antes del código evita que las primeras features creen precedentes incompatibles.

## What Changes

- Crear ADRs para las decisiones fundacionales indicadas por el ARD.
- Registrar alternativas, decisión, consecuencias y relación con PRD/ARD.
- Definir cómo las changes futuras actualizan o reemplazan ADRs.

Ninguna. Son documentos de arquitectura, no requisitos de comportamiento del producto.

### Modified Capabilities

Ninguna.

- Directorio de ADRs y convenciones arquitectónicas del repositorio.
- Issue #20 y decisiones de persistencia, import/export, IDs, estado de UI e impacto.
